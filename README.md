# 可噜记账

可噜记账是一款面向个人用户的 Windows 离线支出记账应用。它不要求注册或登录，账目默认只保存在用户自己的电脑中，适合记录和整理日常人民币花销。

当前版本：`0.1.0`

## 主要功能

- 记录、编辑和删除人民币支出，金额精确到分
- 使用一级大类和二级小类整理花销
- 按日期、分类、支付方式和关键词筛选流水
- 查看月度支出、每日趋势、分类占比和上月对比
- 管理自定义分类，包括新增、改名、排序和停用
- 支持 CSV 导入、预览和导出
- 支持完整数据备份与恢复
- 可选择浅色、深色或跟随系统主题
- 可将数据库安全迁移到用户指定的文件夹
- 无网络连接时仍可使用全部首版功能

## 数据与隐私

可噜记账使用随应用运行的 SQLite 本地数据库，用户不需要另外安装数据库软件。

默认数据文件位于：

```text
%APPDATA%\可噜记账\kelu-ledger.db
```

用户可以在应用的“设置”页面更改数据存放位置。迁移时，应用会先创建并校验新数据库，确认账目、分类和设置数量一致后才切换，新位置不可用时不会破坏原数据。

请注意：

- 数据不会自动上传到本仓库或任何云端服务。
- 卸载、磁盘损坏或误删文件可能造成数据丢失，建议定期使用完整备份功能。
- 本地数据库默认不额外加密，主要依赖 Windows 用户账户权限保护。
- Git 已排除数据库、安装包、依赖和构建产物，个人账目不会随源代码提交。

## 安装使用

普通用户只需获得并运行 Windows 安装包：

```text
可噜记账 Setup 0.1.0.exe
```

安装向导允许自行选择安装目录。首次启动时，程序会在当前用户的电脑上自动创建空数据库，不需要安装 SQLite 或其他数据库服务。

当前安装包尚未进行商业代码签名，因此 Windows 可能显示来源或 SmartScreen 提示。请仅使用由项目所有者提供的可信安装包。

## 默认分类

- 餐饮：早餐、午餐、晚餐、零食饮料、外卖、聚餐
- 交通：公共交通、打车、加油、停车、车辆保养、长途出行
- 居住：房租、房贷、物业、水费、电费、燃气、维修
- 购物：日用品、服饰、美妆、数码、家居、其他购物
- 娱乐：电影演出、游戏、旅游、兴趣爱好、会员订阅
- 医疗健康：看病、药品、体检、健身、健康用品
- 教育：书籍、课程、考试、学习用品
- 人情往来：礼物、红包、请客、捐赠
- 家庭：育儿、老人、宠物、家庭公共支出
- 其他：手续费、罚款、临时支出、未分类

## 开发技术

- Electron：Windows 桌面应用外壳和系统能力
- React + TypeScript：应用界面与业务逻辑
- SQLite：本地结构化数据存储
- Tailwind CSS + Radix UI：界面样式与交互组件
- electron-vite：开发和构建
- electron-builder：生成 Windows NSIS 安装包
- Vitest：自动化测试

## 本地开发

开发环境需要安装 Node.js 和 npm。克隆项目后，在项目目录执行：

```powershell
npm install
npm run dev
```

常用命令：

```powershell
npm run typecheck  # TypeScript 类型检查
npm test           # 运行自动化测试
npm run build      # 构建应用
npm run dist:win   # 生成 Windows 安装包
```

构建完成后，安装包输出到本地 `release` 文件夹。该文件夹不会提交到 Git。

## 项目结构

```text
build/                    应用图标等打包资源
src/main/                 Electron 主进程与数据库逻辑
src/preload/              主进程与界面之间的受限接口
src/renderer/             React 用户界面
src/shared/               共用类型、业务逻辑和测试
codex.md                  产品文档与长期协作约定
package.json              依赖、命令和打包配置
```

## 当前范围

首版只处理单人、单账本、人民币支出。暂不包含收入、转账、借贷、多币种、云同步、多人共享、预算提醒、票据识别和自动更新。

完整产品规则、数据规范和测试要求见 [codex.md](codex.md)。
